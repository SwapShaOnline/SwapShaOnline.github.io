SwapSha Publisher

Privacy policy

Last updated: 16 November 2026

SwapSha Publisher is a personal script run by the creator of SwapSha on their own computer. It is used only with the creator's own accounts.

What it accesses

With the creator's permission, it uses the YouTube Data API to upload videos and thumbnails to the SwapSha YouTube channel, change their visibility, and delete the creator's own uploads. It uses the Instagram API to publish Reels to the SwapSha Instagram account. It does not read data about viewers or any other account.

Where data is kept

Sign-in tokens are stored only on the creator's computer. The tool has no server and no database, and it does not use analytics or cookies.

Sharing

Nothing is sold or shared with anyone. Data goes only to Google (YouTube) and Meta (Instagram), to carry out the uploads.

Google API data

SwapSha Publisher's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at Google account permissions and in Instagram's settings under Apps and websites. Deleting the stored tokens removes everything the tool keeps.

Contact

Through the SwapSha YouTube channel or X.
